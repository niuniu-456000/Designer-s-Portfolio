# Purpose

TASKS.md defines the execution workflow for Enterprise Dashboard OS.

Unlike AGENTS.md, which defines global rules,
TASKS.md defines repeatable execution tasks.

Every dashboard generation should follow one of the workflows below.

# Execution Rules

Always execute tasks sequentially.

Never skip Business Analysis.

Never generate UI before System Hero.

Never generate Components before Dashboard Grammar.

Never generate React before Design System.

Always perform Quality Validation before final output.
